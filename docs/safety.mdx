## Hook and note behavior

| Behavior | What it means |
| --- | --- |
| Commits always land | Annotation runs after Git records the commit. If it fails, the commit stays and a message explains why. |
| Conflicting notes are preserved | Import skips a commit with a different existing note. A push stops when the notes cannot be reconciled. |
| Your hooks keep running | Attributed edits only its own marked block in each hook file and backs up the previous file. Uninstall removes just that block. |
| Attribution never blocks an agent | Agent hooks report failures without stopping the tool. Copilot denies a tool call when a pre-tool hook fails, so Copilot checkpoints print the error and exit 0. |
| Each agent records its own edits | Copilot and Devin also run `.claude/settings.json` hooks. The Claude Code hook skips their input, so their edits are never attributed to Claude Code. |
| Readable without Attributed | Notes are plain Git notes. `git notes --ref=attributed show <commit>` works after uninstalling. |
| No network of its own | The only network traffic is the pre-push hook fetching and pushing `refs/notes/attributed` to the remote you are already pushing to. `--local-notes` turns that off. |
| No prompts or transcripts | Notes hold line ranges and metadata, never conversation content. |

## Without the binary

A teammate may clone a repository whose `.claude/settings.json` includes Attributed's hooks, without installing Attributed. You may also uninstall the binary but leave the hooks. Either way, every managed hook checks for `git-attributed` first:

- Git commands succeed and print nothing extra.
- Agent hooks exit 0 silently, so the agent keeps working.
- Commits made in the meantime get no note.

When the binary returns, the next commit resumes annotation. It prints `resuming attribution after commits that were not annotated` once. Lines that passed through the unannotated commits show as `untracked`.

Git hooks call the binary by its absolute path. If you move or reinstall it somewhere else, rerun `git attributed install-hooks` so the hooks find it again.

## Where it stops on purpose

- **A push with conflicting notes stops.** This happens when the remote changed or removed one of your notes, or when both sides wrote different notes for the same commit. Nothing changes, and the hook prints the manual merge steps.
- **Annotation stops on divergent history.** If the last annotated commit is not in HEAD's history, Attributed will not guess. Commits still land, and no automatic recovery exists yet.

## Rough edges

- **Unobserved lines count as the commit author.** A line changed with no agent checkpoint is labeled human. Telling missing evidence apart from observed human edits is an open proposal.
- **Concurrent shell edits can be ambiguous.** When two sessions run shell commands on the same file and the agent supplies no event ID, a checkpoint can't always be tied to one session.
- **Attribution is self-reported.** Notes record what local hooks observed. Signing is tracked in [issue #8](https://github.com/amichne/attributed/issues/8).
- **Some agents report less.** Copilot sends no model name, so its lines read `ai:copilot/unknown`. Devin's hooks follow its documentation and have not been run against a real session.
- **Platform and install paths.** Attributed supports Linux and macOS. The Factory and Gemini CLI marketplace installs have not been run against their published branches.

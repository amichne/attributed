Use commit `d4260838249720bcea3a746cce809e5a1955248a` for every comparison. The measurements below describe the unmodified upstream tree on Darwin arm64 with Go 1.27.3 and Git 2.56.1. The module declares Go 1.24 and has no external Go module dependencies. [Pinned tree](https://github.com/comarch/git-byline/tree/d4260838249720bcea3a746cce809e5a1955248a) · [Module declaration](https://github.com/comarch/git-byline/blob/d4260838249720bcea3a746cce809e5a1955248a/go.mod).

## Build and test in a disposable checkout

Run the following blocks in the same shell with Git, Bash, and the measured Go toolchain available on `PATH`. The temporary home keeps hook installation and Git configuration inside the experiment. Leave Git’s global config path unset so tests that create their own home directory get their own configuration.

```sh
scratch=$(mktemp -d)
pin=d4260838249720bcea3a746cce809e5a1955248a
git clone --no-checkout https://github.com/comarch/git-byline.git "$scratch/src"
git -C "$scratch/src" checkout --detach "$pin"
test "$(git -C "$scratch/src" rev-parse HEAD)" = "$pin"
mkdir -p "$scratch/home" "$scratch/tmp" "$scratch/cache"

cd "$scratch/src"
env -i HOME="$scratch/home" PATH="$PATH" TMPDIR="$scratch/tmp" \
  GIT_CONFIG_SYSTEM=/dev/null GIT_TERMINAL_PROMPT=0 \
  GOTOOLCHAIN=local GOTELEMETRY=off GOPROXY=off GOCACHE="$scratch/cache" \
  CGO_ENABLED=0 BASELINE_DIR="$scratch" bash -eu <<'CHECK'
go version
git --version
go list -m all
go list -f '{{.ImportPath}} -> {{join .Imports " "}}' ./cmd/git-byline ./internal/...
go build -trimpath -buildvcs=false -ldflags='-s -w' \
  -o "$BASELINE_DIR/git-byline" ./cmd/git-byline
wc -c < "$BASELINE_DIR/git-byline"
go test -json -count=1 -timeout=15m ./... > "$BASELINE_DIR/test.jsonl"
BYLINE_BIN="$BASELINE_DIR/git-byline" bash scripts/smoke.sh
CHECK
```

The build targets the host platform. Compare binary sizes on the same platform with the same toolchain and flags. The smoke script exercises real Git repositories and local remotes. Read `$scratch/test.jsonl` for per-test events and skip reasons.

## Size before extraction

| Metric | Pinned upstream | Attributed import `11c6d61` |
| --- | ---: | ---: |
| Tracked file content | 379 blobs, 5,090,756 bytes | 201 blobs, 2,362,931 bytes |
| Non-test Go source, including tools | 56 files, 790,161 bytes | 50 files, 717,394 bytes |
| Go test source | 106 files, 1,582,306 bytes | 95 files, 1,458,314 bytes |
| Stripped CLI, Darwin arm64 | 6,218,162 bytes | 6,218,162 bytes |

The upstream binary SHA-256 was `014a8b607030aca787ba16c3c27f517fb58a0b90367452a5b4a2a5ea3b0792c1`. The renamed import binary was `0677b18ced7407a0412230855640e6ad8644ba4c1bd7855704ea5816481753fe`, built with the same flags. The import's tracked total includes 11 Attributed files, 29,399 bytes, that predate or carry out the import. It drops [upstream automation, agent configuration, and documents](/extraction#paths-left-out) and the `tools/validate` gate. The import removes no linked package, so the binary keeps its size. Source counts use Git blob lengths, exclude Git history, and include each tracked path once. Recompute them from the pinned tree:

```sh
git ls-tree -rl HEAD | awk '$2 == "blob" {
  files++; bytes += $4
  if ($0 ~ /_test\.go$/) { tests++; testBytes += $4 }
  else if ($0 ~ /\.go$/) { src++; srcBytes += $4 }
} END {
  print "all tracked:", files, bytes
  print "non-test Go:", src, srcBytes
  print "Go tests:", tests, testBytes
}'
```

## Observed checks

| Check | Result at the pin |
| --- | --- |
| Native CLI build | Passed. Two disposable checkouts produced byte-identical binaries with CGO and module downloads disabled. |
| Go suite | Passed all 23 packages. 1,071 top-level tests and fuzz targets passed, plus 1,777 subtests. |
| PromptScript checks | Skipped `TestCheckPromptScriptOnRepo`, `TestCheckDriftDetectsMutation`, and `TestCheckDriftMissingGeneratedFile`. The optional PromptScript CLI was unavailable. |
| Binary smoke suite | Passed all 17 stages, including partial staging, rebase, linked worktrees, hook coexistence, independent clones, and refusal of conflicting or rewritten remote notes. |
| Stock Git after uninstall | Passed in a disposable repository. A synthetic Claude edit produced a version 4 note with one AI-attributed line. Stock Git returned byte-identical note content before and after `uninstall --git`. |
| Unknown authorship | Failed the proposed guarantee. With Git hooks installed and zero checkpoints, committing a new one-line file produced a note with `author: human` and the committer’s identity. |
| Renamed import | Passed at `11c6d61`. 22 packages, 993 top-level tests and fuzz targets, and 1,565 subtests passed with no skips. The excluded `tools/validate` accounts for the whole difference: 78 passed and 3 skipped top-level tests, plus 212 subtests. All 17 smoke stages passed with `ATTRIBUTED_BIN` set to the renamed binary. |
| Downstream acceptance | Not run. The import renames upstream but removes no capability yet. |

The measured runs cover one OS and architecture. The full upstream validation driver and hosted CI matrix were not run. Live harness sessions, exhaustive crash injection, and ambiguous concurrent capture still need direct evidence.

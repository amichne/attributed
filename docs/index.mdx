Attributed records which lines an AI agent wrote, commit by commit. Agent hooks snapshot each file before and after the agent edits it. When you commit, a Git hook matches those snapshots to what Git actually committed and writes the result to a Git note.

![git attributed blame shows Ada's lines as human and Claude Code's lines as AI](/assets/blame.gif)

## Install

The agent plugins provide setup commands and require the binary on your PATH. On macOS or Linux:

```bash
brew install amichne/tap/git-attributed
```

Or build it with Go 1.24 or later. Put `$(go env GOPATH)/bin` on `PATH`, or `$(go env GOBIN)` if you set it:

```bash
go install github.com/amichne/attributed/cmd/git-attributed@latest
```

Git runs the binary as `git attributed`.

### Install through a Homebrew mirror

The tap ships a cask that downloads one file: the release archive for your platform, pinned by SHA-256. It needs no toolchain and has no dependencies. To install without reaching GitHub, mirror two things:

| Mirror | Of |
| --- | --- |
| A Git repository | `https://github.com/amichne/homebrew-tap.git` |
| A file proxy with the same layout | `https://github.com/amichne/attributed/releases/download` |

Then tap the Git mirror and point the formula at the file proxy:

```bash
brew tap amichne/tap https://git.example.internal/mirrors/amichne/homebrew-tap.git
export HOMEBREW_GIT_ATTRIBUTED_URL_ROOT=https://artifacts.example.internal/github-releases/amichne/attributed/releases/download
brew install amichne/tap/git-attributed
```

Replace the example hosts with your own. With the variable set, Homebrew fetches `<root>/v0.1.0/git-attributed_v0.1.0_darwin_arm64.tar.gz` and never falls back to GitHub; the checksum in the cask still has to match. `HOMEBREW_ARTIFACT_DOMAIN` does not cover this cask, because Homebrew rewrites only bottle downloads with it.

Each archive includes `LICENSE` and `LICENSE.upstream`. Every release publishes `checksums.txt` and a build provenance attestation that `gh attestation verify <archive> --repo amichne/attributed` checks.

## Quick start

For Claude Code, install the agent and Git hooks from your repository:

```bash
git attributed install-hooks --agent claude --git
```

Let Claude Code edit a file, commit the change, then inspect the attribution:

```bash
git attributed blame path/to/file
git attributed verify
```

By default, the Git pre-push hook shares attribution notes with the remote you push to. Add `--local-notes` when installing the Git hooks to disable automatic note sharing.

## Supported agents

`--agent` takes one agent, a comma-separated list such as `claude,copilot`, or `all`. Without it, `install-hooks` installs the Claude Code and Factory hooks.

| Agent | `--agent` | Hook file | Before the hooks run |
| --- | --- | --- | --- |
| Claude Code | `claude` | `.claude/settings.json` | Nothing |
| Factory | `droid` | `.factory/hooks.json` | Nothing |
| Codex | `codex` | `.codex/hooks.json` | Trust the project, then approve the hooks in `/hooks` |
| GitHub Copilot CLI | `copilot` | `.github/hooks/git-attributed.json` | Trust the folder |
| Devin CLI | `devin` | `.devin/hooks.v1.json` | Nothing documented |

Add `--user` to write the user-level files instead: `~/.claude/settings.json`, `~/.factory/hooks.json`, `$CODEX_HOME/hooks.json`, `$COPILOT_HOME/hooks/git-attributed.json`, and `~/.config/devin/config.json`.

The Claude Code, Factory, Codex, and Copilot hooks were tested against real sessions. The Devin hooks follow Devin's documentation, which does not list the input of its file tools, so Attributed accepts the usual spellings. Copilot sends no model name, so its lines read `ai:copilot/unknown`.

Copilot and Devin also run the hooks in `.claude/settings.json`. Attributed's Claude Code hook recognizes their input and skips it, so their edits are recorded only by their own hooks and never as Claude Code's.

## Agent plugins

The Claude Code, Factory, and Gemini CLI packages each provide `/git-attributed-setup`. Run it from the repository you want to track, then restart the agent so it picks up the hooks.

| Agent | Package source |
| --- | --- |
| Claude Code | [Claude Code marketplace](https://github.com/amichne/attributed/tree/harness/claude) |
| Factory | [Factory marketplace](https://github.com/amichne/attributed/tree/harness/factory) |
| Gemini CLI | [Gemini CLI extension](https://github.com/amichne/attributed/tree/harness/gemini) |

The [agent setup guide](https://github.com/amichne/attributed/tree/main/marketplace/harness) has setup commands for Codex and Copilot, and the hook files to copy for Cursor, VS Code, Windsurf, Grok, OpenCode, and Gemini CLI. After copying one, run `git attributed install-hooks --agent none --git --project` in the repository.
